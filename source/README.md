# Исходный код приложения

Здесь лежит восстановленный исходный код текущего кандидата регулятора громкости:

- `app/src/main/java/` — Java-код приложения и классы redesign;
- `app/src/main/res/` — ресурсы, строки, массивы и графика;
- `app/src/main/AndroidManifest.xml` — манифест приложения.

Это исходный снимок восстановленной версии APK, а не новый проект, созданный
с нуля в Android Studio. Текущая воспроизводимая сборка использует локальный
Android toolchain и APK-патчинг. Готовый APK находится в GitHub Release.

Для изменений сначала проверьте целевой Android API 18 и сохраните пакет,
разрешения overlay и совместимость с Community-конфигурацией магнитолы.
