# Техническое задание: Регулятор громкости

## 1. Цель

Предоставить компактный плавающий регулятор громкости для Android-магнитолы Geely Coolray с предсказуемым управлением касанием и безопасным поведением при запуске, смене настроек и восстановлении окна.

## 2. Целевая платформа

- Android 4.3, API 18; проверка на эмуляторе ARM 1920×720 и последующая приёмка на магнитоле.
- Существующий пакет и совместимый способ подписи сохраняются в пределах тестовой ветки.
- Приложение работает без сети.

## 3. Функциональные требования

1. Показывать плавающую шкалу поверх других приложений после выдачи overlay-разрешения.
2. Поддерживать вертикальную и горизонтальную ориентации, размеры, длину, положение процента и три визуальных стиля.
3. Изменять выбранный аудиоканал и сохранять настройки между перезапусками.
4. При включённой защите принимать изменение только после удержания 250, 500 или 1000 мс.
5. После подтверждения удержания использовать относительное движение, исключая скачок к координате пальца.
6. Игнорировать короткий тап, быстрый свайп, второй палец и отменённый жест.
7. Показывать мягкую подсветку подтверждённого удержания; дать отдельный переключатель подсветки, доступный только при включённой защите.
8. Автоматически скрывать шкалу по существующему таймеру и корректно отменять отложенные callbacks.
9. При чтении настроек не менять текущую громкость самопроизвольно.
10. Не добавлять сеть, рекламу, новые сервисы или внешние ссылки в рабочий UI.

## 4. Нефункциональные требования

- Сборка должна устанавливаться на API 18.
- Все изменения должны проходить локальные тесты, проверку конечного DEX и подписи APK.
- Сценарии, которые нельзя проверить на эмуляторе (реальная магнитола, vendor UI, физический мультируль), фиксируются как открытые.
- Размер и расположение элементов должны оставаться читаемыми на штатном экране.

## 5. Матрица скриншотов

Обязательные снимки для каждого тестового выпуска:

| ID | Состояние | Что проверяем |
|---|---|---|
| S-01 | Настройки | защита, задержка, подсветка и сохранение |
| S-02 | Обычная шкала | положение, процент и базовая геометрия |
| S-03 | Сегментированный стиль | равномерность сегментов и цвета |
| S-04 | Удержание включено | контур/ореол подтверждённого жеста |
| S-05 | Удержание выключено | отсутствие подсветки при сохранённом управлении |
| S-06 | После перезапуска | автоскрытие и восстановление параметров |

Снимок не является доказательством звукового эффекта или работы на автомобиле; эти свойства проверяются отдельным runtime-сценарием.

## 6. Приёмка

Кандидат принимается для планшетного теста после успешной сборки, установки на API18, проверки S-01…S-06 и сверки SHA-256. Приёмка на магнитоле требует отдельной записи с моделью устройства, прошивкой, сценариями и ограничениями.

## 7. Артефакты выпуска

- APK прикрепляется к GitHub Release.
- README содержит заметную кнопку скачивания через `releases/latest`.
- Отчёты и снимки хранятся в каталоге `output/` или прикрепляются к выпуску.
