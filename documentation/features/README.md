Исходная точка — локальная сборка redesign12/code35 с исправлением запуска автоскрытия. Её сборка и статические проверки выполнены в предыдущей задаче; автомобильная приёмка ещё открыта. Перед реализацией проверить актуальный код и APK: файлы в рабочей папке могут измениться.

Запускать задачи последовательно. Каждая заканчивается отдельным проверенным APK и отчётом, следующая сохраняет результат предыдущей. F-02 можно реализовать отдельно от F-01, сохранив описанный контракт взаимодействия. F-03 в итоговой сборке должна поддерживать настройки обеих функций. При параллельной разработке потребуется отдельная интеграция; автоматически её не подразумевать.

Общие ограничения: Android 4.3/API18, существующие пакет и сертификат; сохранить размеры, стили, положение процента, явное ручное управление, исправления аудио при применении настроек и автоскрытие после запуска. Не менять target SDK в рамках этих задач. Не переносить новые правила на ползунки эквалайзера и микшера без отдельного требования. Без commit/push/публикации, пока пользователь отдельно их не поручит.

Перед существенными изменениями проверить Git и сохранить восстанавливаемую копию затрагиваемых файлов и предыдущего APK. На момент подготовки ТЗ у main нет коммитов, файлы untracked; это не является сохранённой историей Git. Не добавлять ключи подписи в отчёты и архивы настроек.

Для каждого этапа: изучить владельцев кода, реализовать минимальный объём, выполнить проверки, собрать API18 APK с новым versionCode и уникальным именем, проверить сертификат/пакет/ресурсы/DEX035 и провести обязательную независимую проверку по AGENTS.md. Отдельно сообщить результаты локальных тестов, эмулятора и магнитолы. Если устройства нет, выдать кандидат и незакрытый перечень приёмки; не объявлять автомобильную проверку успешной.
