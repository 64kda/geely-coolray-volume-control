# Сменные иконки — кандидат redesign18

Продолжение: исправление качества графики и доступности выбора в redesign19 описано в [ICON_HD_FIX_RU.md](ICON_HD_FIX_RU.md). Настоящий отчёт сохраняет факты предыдущего кандидата.

Дата: 24.11.2026. Статус: локальный кандидат, runtime-приёмка открыта.

## Результат

По умолчанию выбран №07 «Регулятор». Во вкладке «Работа приложения» добавлены четыре кнопки-превью: №07 «Регулятор», №06 «Уровни», №08 «Динамик», №10 «Слайдер». Выбор подписан «Выбрана» и обведён зелёным. Сброс вкладки возвращает №07. Выбор хранится в отдельном ключе Common/Launcher icon; обычное сохранение старой формы его не очищает.

Графика — векторная адаптация согласованных концептов, а не вырезки презентационного изображения. SVG-мастера: design/icon/options/icon-{7,6,8,10}.svg. Превью: design/icon/options/production-preview.png. Каждая иконка экспортирована непосредственно из вектора в 36/48/72/96/144/192 px. Превью в настройках загружается из ресурса повышенной плотности. Генератор старой основной иконки теперь вызывает тот же источник и не возвращает прежний дизайн.

Четыре launcher activity-alias с постоянными именами LauncherIcon7/6/8/10 направлены в прежнюю MainWindow. Сама Activity остаётся включённой, её прямые старые ярлыки продолжают иметь доступную цель. Сначала включается новая точка входа, затем отключаются остальные; при ошибке выполняется восстановление прежней. При следующем открытии согласуются сохранённый выбор и состояния компонентов. Используется API1 setComponentEnabledSetting/DONT_KILL_APP, без API33 batch API. Старый SetAppIcon Free/Pro остаётся отключённым.

Внешние лаунчеры могут кешировать значки; старый закреплённый ярлык отключённого alias может потребовать повторного добавления. Смена иконки приложения не подтверждает поведение конкретного лаунчера магнитолы.

## Дизайн-проверка

Источник: production-preview.png, реальные SVG→PNG экспорты; строка 48 px внизу показана 1:1. Для выбора использована сетка 2×2 с превью и текстовой отметкой: узнавание по видимым вариантам, Nielsen heuristic #6 — Recognition rather than recall. Оценка набора графики: 3/4, нужна runtime-проверка посадки в конкретном лаунчере. У №07 мелкие световые грани на 48 px становятся менее различимы; они декоративны, основной круг/голубая дуга/белый указатель сохраняются. Это polish, а не функциональный дефект; Nielsen heuristic #8 — Aesthetic and minimalist design.

Проверка дизайна собранного приложения НЕ выполнена: нет runtime-снимков. Оценка макета не выдается за оценку работающего экрана. Пользовательский выбор №07 по умолчанию сохранён.

## Процесс и открытые шаги

Применён ub-mode: минимальная отдельная модель переключения, проверки, затем API18-адаптер и UI; без изменения аудиометодов. TokenEconomizer оставлен включённым, status прочитан, envfacts/auto/nudge, hooks/trust не менялись. В исходной рабочей директории уже были незакоммиченные изменения двусторонней шкалы, автоскрытия и документов — сохранены.

Независимый critic: существенных блокеров в производственном коде не обнаружено. Найден дефект Android-автотеста: исходная иконка устанавливалась один раз перед внутренним циклом, поэтому фактически не проверялись все 16 пар. Исправлено — исходный вариант устанавливается перед каждым целевым переключением; повторная компиляция и подпись тестов прошли. Runtime и проверка стороннего лаунчера остаются открытыми. Критик работал read-only и не запускал приложение.

Obsidian CLI ответил, что приложение не запущено. Проверенный vault D:/Obsidian/64KDA Space доступен для чтения, но расположен вне разрешённых каталогов записи этой среды. Поэтому здесь сохранён локальный отчёт; перенос значимых итогов в заметку функции, обзор/план и реестр сборок **остаётся открытым**. Существующие заметки не изменялись.

Следующий обязательный шаг: запустить run-icons-android.ps1 на отдельном API18/mdpi эмуляторе; проверить default07 после обновления, все четыре реальных пункта запуска, сохранение, снимки сетки на 800×480 и 1920×720, визуально сравнить с production-preview; затем проверить лаунчер магнитолы. До этого кандидат нельзя считать полностью принятым.
