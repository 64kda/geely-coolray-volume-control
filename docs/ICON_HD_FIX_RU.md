# Иконки HD и доступный выбор — redesign19

Дата: 24.11.2026. Локальный кандидат, runtime-приёмка остаётся открытой.

## Причина обращения и исправление

Пользователь не нашёл выбор иконки и прислал скриншот размытой иконки №07 в лаунчере. Ранее выбор был спрятан во вкладке «Работа приложения» в горизонтальной ленте, а внутрь APK попала упрощённая векторная адаптация понравившегося растрового концепта. На скриншоте значок занимает примерно140px; отдельной крупной графики для его точки входа не было, использовались density-ресурсы36–192px. При выборе48px и последующем увеличении детальность теряется. Фактическую плотность устройства и выбранный кеш лаунчера без runtime-доступа установить не удалось; конкретный путь масштабирования не объявляется измеренным.

1. В шапку основного экрана добавлена постоянная кнопка «Иконка» с description «Изменить иконку приложения». Она сразу открывает «Работа приложения»; блок выбора перенесён в начало страницы, перед автозапуском. Нет необходимости искать вкладку в горизонтальной ленте.
2. Для №07 создан детальный мастер1254×1254 с металлической ручкой и голубой дугой. Он заменяет прежнее упрощённое изображение. Мастер: design/icon/options/icon-7-master.png. Векторная версия сохранена как icon-7-vector-legacy.svg; она больше не источник экспорта.
3. Все четыре точки входа, приложение, реальная Activity и старые Free/Pro alias ссылаются на отдельные drawable-nodpi-v4/launcher_art_{7,6,8,10}.png по512×512. Маленькие density-экспорты сохранены, но не используются для значка лаунчера. Превью в приложении использует ту же крупную графику.
4. У созданного мастера внутри непрозрачной плитки обнаружен alpha252/253. При экспорте alpha>245 нормализован до255, сглаженные прозрачные углы сохранены. Это техническая подготовка PNG, без изменения формы/композиции.

Крупный экспорт не гарантирует сброс кеша конкретного лаунчера. При сохранении старого вида после обновления может потребоваться убрать прежний ярлык и добавить приложение из меню заново. Не следует очищать данные приложения: настройки нужно сохранить.

## Дизайн-проверка

Источник пользовательского дефекта: приложенный скриншот лаунчера; модель устройства и версия установленного APK не подтверждены. Источник проверки графики: просмотрен design/icon/options/production-preview.png, собранный из реальных экспортов; есть отображение48px1:1. Новый №07 имеет различимые блики/ободок и сохраняет голубую дугу. Превью графики:3/4; запас для визуальной приёмки на фактической магнитоле остаётся. Решение вынести видимую кнопку «Иконка» устраняет необходимость вспоминать скрытую вкладку — Nielsen heuristic #6, Recognition rather than recall. Увеличение исходной графики и отказ от упрощения сохраняют детали при отображении крупного значка — Nielsen heuristic #8, Aesthetic and minimalist design.

Дизайн собранного экрана приложения не оценивался: runtime-снимки недоступны. Превью не заменяет этот этап.
