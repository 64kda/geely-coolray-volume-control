## Android runtime

Отдельный эмулятор VolumeRelease_API18: ARM, Android 4.3/API18, 1920×720 mdpi. APK установлен поверх опубликованной redesign15 без удаления приложения.

Проверено:

- приложение запускается; два окна шкал появляются по разным краям;
- короткий тап и неподвижное удержание не меняют громкость; подтверждённое движение слева и справа меняет STREAM_MUSIC;
- режимы только слева и только справа создают одну шкалу на выбранном краю;
- общий таймер скрывает обе шкалы и проценты, удержание на скрытой области показывает обе стороны, после отпускания они снова скрываются;
- в независимом режиме удержание слева показывает левую сторону, правая остаётся скрытой; видимость проверена по пикселям снимка;
- настройки открываются; получены реальные скриншоты. В логе прогона нет FATAL EXCEPTION и VerifyError.

Проверка прозрачности учитывает разницу между отдельными окнами слева/процентов и дочерней правой шкалой. Для правой стороны alpha контейнера сама по себе не подтверждает видимость; использованы снимки экрана.

## Визуальная проверка

Design-review: 3/4 по снимкам R17-02, R17-08 и R17-10. Две шкалы отображают один уровень, удержание выделяется контуром: Nielsen heuristic #1 — Visibility of system status. Переключатель совместного показа подписан действием и находится рядом с настройками шкалы: Nielsen heuristic #4 — Consistency and standards.

Осталась небольшая неточность прежней подсказки под положением процента: она говорит о левой или правой шкале, не упоминая режим обеих сторон. Для этого выпуска поведение и тексты приложения дополнительно не менялись. Основание: Nielsen heuristic #10 — Help and documentation. Для снимков настроек overlay выключен штатной кнопкой, чтобы он не перекрывал подписи.

## Ограничения

Не проверены физическая магнитола, мультируль и автомобильное аудио, runtime мультитач, сон/пробуждение и полная матрица старых расположений, каналов и размеров. Локальные модели и DEX-проверки не заменяют эти сценарии. Выпуск предназначен для тестирования.

Сборка использует унаследованный локальный Android toolchain и восстановление/патчинг исходного APK. `source/build-support/` хранит изменённые части сборки; автономная сборка из чистого Git checkout не подтверждена.

Критик проверил документы и план публикации. Замечания по статусу APK, происхождению сборки и порядку переключения ссылки учтены. Итоговый результат проверен основным агентом; отдельного независимого ревью нового runtime-прогона не было. Применены ub-mode и TokenEconomizer; настройки hooks/trust не менялись.
